# Native Syncshell Web UI

This candidate ports the modified Syncshell Web UI to Preact.
The behavioral reference is Syncshell commit
`ec4e2a83dacb44fffbae376e2034028ddb76ad3d`, based on Syncthing v2.1.3.
The original Syncthing authors and license notices remain credited in About.

`app/` contains native components; `client/` contains shared browser code.
`modern/` is the shipped static tree. Its `compiled/` directory and entry point
are generated by `npm ci && npm run build` from this directory. The build also
updates `SHA256SUMS`. Static assets stay in that tree rather than maintaining
separate source and release copies. `dist/` is a disposable complete package
for isolated testing.

The existing host theme helper prepares Modern and Omarchy profiles from the
shipped tree. Syncthing serves the output. End users need no Node server, build
step, runtime CDN, or Angular installation.

Browser tests live under `tests/webui/` in the repository root. Original-code
comparisons read the pinned Git snapshot. A remote test cache may be supplied
through `SYNCSHELL_WEBUI_REFERENCE`, pointing to its `webui/modern` directory.

Conflict filesystem actions still require the separately identified host
integration. The local review runner injects the existing test capability;
its Python handler and adapter script are not release assets.
